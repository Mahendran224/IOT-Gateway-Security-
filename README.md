##  About the Project

As the number of IoT devices continues to grow, keeping them secure is becoming increasingly important.

This project focuses on building an **IoT Security Gateway using Raspberry Pi** that monitors communication between IoT devices and helps identify unusual activities.

Using ESP32, MQTT, and Raspberry Pi, sensor data is collected and processed at the gateway. Anomaly detection techniques are then used to identify abnormal patterns, while a Flask-based web dashboard makes it easy to monitor everything in one place.

##  Technologies Used

- ESP32
- Raspberry Pi 4
- Python
- MQTT and Mosquitto
- Flask
- Machine Learning
- Arduino IDE

##  Project Structure

- `Arduino_code/` – ESP32 programs.
- `images/` – Project images.
- `anomaly_detector.py` – Anomaly detection.
- `anomaly_classifier.py` – Anomaly classification.
- `app.py` – Flask web application.
- `Dashboard_demo_video.mp4` – Project demonstration.

##  Getting Started

Clone the repository:

```bash
git clone https://github.com/Mahendran224/IOT-Gateway-Security-.git
```

Navigate to the project:

```bash
cd IOT-Gateway-Security-
```

Create and activate a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install the required dependencies and configure the MQTT broker before running the application.
